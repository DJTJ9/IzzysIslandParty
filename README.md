# Izzy's Island Party

Lokale Party-Minispiel-Sammlung für 1–4 Spieler — gegeneinander oder gegen Computergegner.
Abschlussprojekt des Studiengangs Games Programming am SAE Institute Hamburg (2026).

**Unity 6000.0.59f2 · C#**

## Minispiele

| Minispiel | Umgesetzt von |
|---|---|
| Bowling Battle | Tjark Dreyer |
| Minigolf Mayhem | Tjark Dreyer |
| Swaggy Snapshots | Tjark Dreyer |
| Fishing Frenzy | J. Albrecht |
| Jetski Joyride | J. Albrecht |
| Hasty Hurdles | J. Albrecht |

## Team

Zweierteam, entwickelt von November 2025 bis März 2026.

- **Tjark Dreyer** ([@DJTJ9](https://github.com/DJTJ9)) — Bowling Battle, Minigolf Mayhem, Swaggy Snapshots
- **J. Albrecht** ([@heyitsjudymoody](https://github.com/heyitsjudymoody)) — Fishing Frenzy, Jetski Joyride, Hasty Hurdles

Spielrahmen, Menü, Spielerverwaltung und Integration der Minispiele entstanden gemeinsam.

## Projekt öffnen

Repository klonen und den Ordner in Unity Hub als Projekt hinzufügen (Unity 6000.0.59f2).
Das Repo enthält Art-Assets und Preview-Clips und ist entsprechend groß (~1,8 GB Historie).

## Branches

`main` enthält den finalen Abgabestand (v1.0, März 2026).
Die `feature/*`-Branches dokumentieren die Entwicklung der einzelnen Minispiele.
